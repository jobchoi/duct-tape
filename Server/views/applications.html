설치 앱 등록

검토된 MSI 어댑터를 사용합니다. setup.exe의 선행 구성요소와 일반 앱은 MSI 단독 설치를 검증한 뒤 공개하세요. Argos MDM은 다운로드 후 수동 설치·등록합니다. 등록 시에는 초안으로 보관됩니다.

MSI·EXE·CAB·DLL만 포함하세요. 계정·키·설정 파일은 제외합니다. 최대 512 MB이며 같은 앱 버전은 덮어쓸 수 없습니다.

PC별 작업 현황

각 작업에 선택 앱과 패키지 버전을 고정합니다. 다운로드 진행은 실제 전송량입니다.

MDM 수동 설치·기기 등록

목록에서 MDM ZIP을 다운로드하고 압축을 푼 뒤 setup.exe를 실행하세요. 자동 설치·등록 작업은 생성하지 않습니다.

설치 후 Windows 설정 → 계정 → 회사 또는 학교 액세스 → 장치 관리에만 등록에서 승인된 계정으로 진행하세요. 등록 정보는 위 버튼을 눌렀을 때만 표시됩니다. 자리를 비우기 전에 숨겨 주세요.
