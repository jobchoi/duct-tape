Office와 한컴 설치를 준비하고 실행합니다.

처음 사용하는 PC

  1. 실행 도구 다운로드
  2. ZIP 압축을 모두 풀고 InstallAgent.bat을 실행하세요.
  3. 관리자 권한 요청을 승인하면 바탕화면 바로가기가 생성되고 연결 페이지가 열립니다.

실행 도구 연결에는 Office·한컴 매체가 필요하지 않습니다. 실제 셋업에는 정식 매체와 라이선스 키가 필요합니다.

처음이면 위 실행 도구를 설치하세요. 설치 후 바탕화면 바로가기가 만들어집니다.

기존 Office·한컴 제거 및 설치가 진행됩니다. PC를 켜 두세요.

실시간 작업 진행

    처음 접속하는 PC인가요?

    브라우저에서 설치하려면 PC의 실행 도구가 한 번 준비되어야 합니다. 담당자가 매체와 키를 준비한 뒤 InstallAgent.bat을 실행하면 서버에 자동 연결 요청을 보냅니다. 관리자가 승인하면 바탕화면 바로가기로 접속해 셋업 버튼을 누르세요.

    이 화면에는 등록 코드나 로그인 키를 입력하지 않습니다.
