# MDM 수동 설치·등록 지원

2026-10-16 사용자 결정: 백그라운드 무인 등록에 의존하지 않고 설치 원본을 PC마다 들고 다니는 과정을 줄인다.

## 관리자 준비

1. 서버 배포 원본 `ArgosMDM/` 아래 `ArgosMDMSetup.msi`, `setup.exe`를 둔다.
2. `/admin/apps`에서 Argos 원본을 초안으로 등록하고 검토 후 공개한다. 기존 공개 Argos도 새 화면에서 다운로드 전용으로 표시된다.
3. 필요하면 배포 원본 `Config/ArgosEnrollment.json`에 아래 형식으로 정보를 저장한다. Docker에서는 호스트의 배포 원본 디렉터리이며 소스 저장소 Config와 혼동하지 않는다.

```json
{"server_url":"https://관리서버주소", "email":"등록메일", "username":"공통계정", "password":"비밀번호"}
```

실제 값은 Git·설치 ZIP·채팅에 넣지 않는다. Linux에서는 `chmod 600 Config/ArgosEnrollment.json`으로 제한한다. 파일이 없거나 권한이 넓으면 정보가 표시되지 않는다. 비밀번호는 선택 사항이며 저장하지 않아도 다운로드는 가능하다. 이 파일은 평문이므로 보호된 서버에서만 사용한다.

## 클라이언트 작업

관리자 승인을 받은 PC의 기존 바로가기로 접속한 뒤 v2 앱 화면(`/client/apps`)에서 **MDM ZIP 다운로드**를 누른다. 별도 v2 에이전트 실행이나 설치 작업 생성 없이 브라우저로 받는다. ZIP 전체를 압축 해제하고 `setup.exe`로 수동 설치한다. **등록 URL·계정 확인**을 눌러 Windows 설정 → 계정 → 회사 또는 학교 액세스 → 장치 관리에만 등록에서 수동 등록한다. 관리자도 `/admin/apps`에서 같은 정보를 확인할 수 있다.

등록 정보는 인증된 관리자 또는 승인된 PC 사용자에게만 명시적 요청 시 제공한다. 따라서 승인된 PC 사용자는 공통 비밀번호를 볼 수 있다. 정보 API와 다운로드는 no-store이며 일반 앱 목록·공개 에이전트 ZIP에는 포함하지 않는다. 표시 후 1분, 정보 숨기기 클릭 또는 탭을 벗어날 때 화면에서 제거한다. 이 동작은 이미 열람한 값이나 사용자가 저장한 파일까지 회수하지 않는다.

Argos 신규 자동 설치 요청은 서버에서도 409로 차단한다. 변경 전에 이미 생성된 작업은 이 변경으로 취소되지 않으므로 배포 전에 기존 작업을 확인한다. 수동 설치·등록 완료는 서버가 자동 확인하거나 완료로 추정하지 않는다. 현재 다운로드는 브라우저 메모리에 ZIP을 받은 뒤 저장하므로 저사양 PC에서는 메모리 여유가 필요하다.

## 검증 범위

임시 DB와 모의 설치 원본으로 인증·승인, 초안/공개 다운로드, 자동 작업 차단, 계정 정보 명시적 조회·캐시 방지·권한 제한을 테스트한다. 실제 Argos 설치·기관 등록은 전용 Windows PC에서 확인해야 한다.
