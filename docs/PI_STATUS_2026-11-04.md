서버 재시작·Compose 수정·컨테이너 재생성·파일 이동은 수행하지 않았다. 재생성 전에 기존/새 데이터 경로의 실제 대상과 Compose 위치를 확인해야 한다. 기존 마운트를 확인하지 않고 새 경로의 빈 디렉터리로 교체하면 DB나 설치 원본이 사라진 것처럼 보일 수 있다.

진단 스크립트: `Scripts/diagnostics/pi-status.sh`. 원시 로그·키·설정 본문은 수집하지 않았다. 로컬 임시 보고서는 `/tmp/duct-tape-pi-status.log`이며 영구 보존을 보장하지 않는다.

### 백업·복구

각 프로젝트의 `backups/migration-20261104-122953/`에 백업을 두었다. DuctTape는 코드·환경 파일, DB·설치 원본·임시/업로드 자료를, File Browser는 DB·설정·파일과 보존 볼륨을 백업했다. 백업에는 비밀값이 포함될 수 있으므로 공개하거나 Git에 추가하지 않는다.
