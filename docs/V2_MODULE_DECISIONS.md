# v2 기능 구성 결정·제안

기준: 2026-10-21. 사용자 요구를 기록하고 현재 코드로 확인한 사실과 구현 제안을 구분한다. 이번 작업은 문서화이며 아래 기능 토글·QR 연계·OS 어댑터를 새로 구현한 것은 아니다.

## OS별 기능과 SDK

OS별 API·라이브러리를 이용할 수 있다. 서버 공통 로직과 OS 전용 어댑터를 분리한다. Windows 클라이언트의 BIOS 정보 등은 Windows 에이전트에서 수집하고 공통 형식으로 서버에 보고한다. Raspberry Pi의 Linux 서버가 Windows 전용 SDK를 직접 실행한다고 가정하지 않는다. Python 라이브러리나 PowerShell로 가능한 기능은 그대로 사용하고 네이티브 SDK가 필요한 기능만 어댑터로 감싼다. 실제 SDK 선정은 해당 기능 구현 시 공식 지원 OS·라이선스·ARM64 지원을 확인한다.

현재 근거: Modules/01_GetInfo.ps1에서 Win32_BIOS.SerialNumber를 읽고 Scripts/ReportStatus.ps1에서 serial로 보고한다. 관리자 portal.js는 device_id로 보고를 연결해 시리얼을 표시한다.

## 블록처럼 켜고 끄는 기능

관리자 **설정 → 기능 관리**에서 검토된 기능을 켜고 끄는 구조를 목표로 한다. 최초 대상은 QR 도구와 MDM 수동 다운로드다. 향후 기능도 고유 ID·버전·필요 플랫폼·의존 기능·권한을 명시한다. 서버 기능 모듈과 PC에 설치하는 애플리케이션 패키지는 별도 종류로 관리한다.

관리자는 제공 기능을 활성화하고 이용자는 허용된 기능/옵션을 선택한다. 화면만 숨기지 않고 서버 API에서도 비활성 상태와 권한을 검사한다. 비활성화는 새 요청을 차단하는 것이며 진행 중인 설치의 자동 중단이나 PC의 앱 제거를 뜻하지 않는다. 의존성이 충족되지 않으면 비활성 사유를 표시한다. 임의 소스 업로드로 서버/SYSTEM 코드를 실행하는 플러그인 시스템은 만들지 않는다.

현재 앱 공개/비공개는 설치 카탈로그의 공개 여부다. 서버 기능 전체를 켜고 끄는 토글은 아직 없다. 먼저 등록된 소수 기능의 설정·권한 검사로 시작하고 범용 플러그인 SDK는 필요할 때 확장한다.

## 시리얼을 QR에 재사용

권장 흐름: 관리자 PC 목록에서 선택 → **QR 만들기** → 보고된 시리얼 자동 입력 → 사용자 이름 선택적 수기 입력 → 미리보기·다운로드. 이름을 입력하더라도 기본 QR 데이터는 시리얼이며 라벨 설명에 이름을 표시하는 방식을 제안한다. QR 안에 이름을 포함하는 별도 형식은 명시적 선택과 스캔 사용처 확인 뒤 추가한다.

반드시 선택한 클라이언트의 serial을 사용하고 서버 자신의 시리얼을 읽지 않는다. 없는 값/제조사 기본 문자열/중복 가능성을 고려해 사용자가 확인·수정할 수 있게 한다. PC 내부 식별은 기존 device_id를 유지하고 시리얼을 유일 인증값으로 사용하지 않는다. 보고 시각을 함께 표시해 오래된 값을 구분한다.

기존 시리얼 수집은 셋업 단계 파일에 연결되어 있고 해당 단계에서 한컴 키도 확인한다. 따라서 신규 등록 PC가 즉시 시리얼을 보고한다고 보장하지 않는다. 실제 구현 때 설치/키와 독립된 장치 정보 수집으로 분리하는 것을 검토한다. 미보고 PC는 확인 전으로 표시하고 수기 입력도 허용한다.

## 설치·블로그 기록

Blogger 도구는 전용 환경 설치와 계정 연결을 분리한다. 사용자는 현재 Google Cloud 프로젝트 생성 단계(최초 안내의 2번)까지 진행했다. API 활성화와 OAuth 계정 연결 전이며 업로드 도구도 아직 없다. 글은 로컬 초안으로 보관하고 자동 게시됐다고 표시하지 않는다.

프로젝트 MD에는 요구·결정·구현 범위·검증·다음 작업만 간결히 남긴다. Blogger는 사실 기반 시행착오 일지, 티스토리는 실행 가능한 절차 중심으로 작성한다. 미구현 기능은 매뉴얼 명령으로 만들지 않는다. 외부 공개 전 민감 정보와 검증 범위를 확인한다.

다음 구현 순서 제안: 단일 QR 생성과 기존 시리얼 연계 → 기능 관리 및 API 제어 → 명단 라벨 출력. Blogger 연결/도구 구축은 별도 진행하며 완료 후 초안 업로드부터 확인한다.
