# DuctTape 개발 일지 — QR에 어떤 정보를 담고 진행 상태는 어떻게 보여줄까

QR 도구를 붙인 뒤 요구가 구체화됐다. 시리얼만 담는 것에서 이름·입학년도·S/N을 함께 출력하도록 바꿨다. 기본 기기 라벨 모드는 기존 참고 도구와 같은 입학년도|이름|S/N 형식으로 인코딩하고 PNG에도 세 항목을 글자로 표시한다. 입력값만 담는 모드는 남겨 두었다.

입학년도는 현재 연도를 기본값으로 채우지만 실제 입학년도를 확인해 수정해야 한다. 구분자로 쓰는 문자나 줄바꿈이 이름·시리얼에 들어오면 형식이 모호해지므로 생성을 막는다. 이번에도 실제 브라우저에서 PNG를 내려받아 독립 디코더로 읽었다. 모의 이름과 연도, 앞자리 0이 있는 시리얼이 원문대로 돌아오는 것을 확인했다. 실물 휴대폰 스캔이나 인쇄 정렬을 검증한 것은 아니다.

운영 중인 라즈베리 서버에서는 Office 작업의 상태가 완료/진행 중 글자로만 구분된다는 피드백도 있었다. 현재 현장 버전과 이벤트 수신을 직접 확인하지 않았으므로 원인은 아직 단정하지 않았다. UI 방향으로는 PC별 현재 단계와 상태 배지, 확인 필요 필터, 선택한 PC의 상세 기록을 제안했다. 색만 바꾸는 대신 문구와 아이콘을 함께 사용하고 다운로드는 실제 바이트 비율, 설치는 정확한 비율을 모르면 경과 시간을 보여주는 방식이다. 이 진행 UI 제안은 아직 구현 결과가 아니다.

블로그 운영 원칙도 돌아봤다. 질문과 시행착오를 기록한다는 목적은 유지하되 여러 AI의 검토를 매번 의무화하면 기록이 무거워질 수 있다. AI는 검토 의견을 내고 최종 발행은 작성자가 결정하는 방향을 제안했다. 이 글도 현장 배포나 학습 효과를 검증한 기록으로 확대하지 않는다. Blogger 인증 연결 전이라 로컬 초안으로 보관했다.
