하나의 작업 기록에서 두 글을 작성하되 같은 본문을 그대로 중복 게시하지 않는다. 작업을 수행한 날짜와 글을 작성한 날짜를 구분한다.

## 기록 헌장

- 실제 수행한 작업과 확인된 근거를 기록한다. 기록에 없는 오류·대화·성과를 만들지 않는다.
- 관찰·추정·검증·향후 계획을 구분한다. 원인을 확인하지 못했다면 미확인으로 남긴다.
- 코드 작성, 모의 테스트, 로컬/브라우저 테스트, 실제 PC 설치, 운영 배포를 구분한다.
- AI의 초안은 실제 작업 기록과 대조한다. 문장 교정은 사실 검증을 대신하지 않는다.
- 비밀번호·키·토큰·기관 식별 정보·내부 주소·장치 식별값은 글과 캡처에서 제외한다.
- 서버 설정·로그 원본·Git diff 전체를 무차별로 외부 AI에 보내지 않는다.
- 사람이 검토한 뒤 공개한다. 자동화 기본값은 초안이며 공개 권한과 분리해 운영한다.
- 의미가 바뀌는 정정은 이유를 남긴다. 같은 작업 재실행으로 중복 글이 생기지 않도록 게시 ID를 관리한다.

## 자동화 범위와 현재 상태

Blogger는 OAuth 인증 후 공식 API의 posts.insert(isDraft=true)로 초안을 올릴 수 있다. 티스토리는 공식 글쓰기 Open API가 종료되었으므로 파일 작성까지 자동화하고 편집기에 직접 입력하는 흐름을 우선한다. 로그인된 브라우저 자동화는 공식 API와 별개이며 현재 구현하지 않았다.

현재 저장소에는 게시 기준, 두 종류의 초안, 최초 설정 안내를 준비했다. 계정 연결·업로드 실행기·예약 실행은 아직 구현/연결하지 않았다. 실제 업로드·공개는 수행하지 않았다.
