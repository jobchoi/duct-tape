# DuctTape v2 — Argos MDM 설치 파일 배포 및 수동 등록 절차

## 적용 범위

MDM 다운로드·수동 등록 지원 변경이 반영된 v2 서버 기준이다. 서버와 기존 에이전트 등록·관리자 승인이 준비되어 있어야 한다. v1 서버에 자동 적용되는 기능이 아니다. 실제 기관 설치·등록은 현장 검증이 필요하다.

## 1. 서버에 설치 원본 준비

서버 배포 원본 디렉터리에 다음 구조로 둔다. 소스 저장소 경로가 아니라 서버가 배포 원본으로 읽는 경로다.

```text
배포원본/
├── ArgosMDM/
│   ├── ArgosMDMSetup.msi
│   └── setup.exe
└── Config/
    └── ArgosEnrollment.json
```

관리자 `/admin/apps`에서 **서버의 Argos 1.1.7 원본을 초안으로 등록**을 누른다. 원본을 검토한 뒤 **검토 후 공개**로 전환한다. 이 버튼은 해당 버전 원본을 위한 기능이다.

## 2. 등록 정보 설정 — 선택 사항

`Config/ArgosEnrollment.json` 형식:

```json
{
  "server_url": "https://관리서버주소",
  "email": "등록용 이메일",
  "username": "등록 계정",
  "password": ""
}
```

실제 기관 정보로 별도 작성한다. 비밀번호는 생략하거나 빈 값으로 둘 수 있다. Linux에서는 배포 원본 디렉터리에서 권한을 제한한다.

```bash
chmod 600 Config/ArgosEnrollment.json
```

이 파일은 평문이다. Git이나 배포 ZIP에 포함하지 않는다. 설정하지 않아도 설치 파일 다운로드는 가능하다. 비밀번호를 저장했다면 승인된 PC 사용자가 화면에서 확인할 수 있다.

## 3. 클라이언트에서 내려받기

1. 등록된 PC의 기존 DuctTape 바로가기로 접속한다.
2. v2 앱 화면(`/client/apps`)으로 이동한다.
3. **MDM ZIP 다운로드**를 누른다.
4. ZIP 전체를 압축 해제한다.
5. 압축 해제된 폴더에서 `setup.exe`를 실행해 수동 설치한다.

MDM은 자동 설치 체크박스를 선택하지 않는다. 다운로드는 에이전트 설치 작업을 생성하지 않는다.

## 4. Windows 기기 등록

1. DuctTape에서 **등록 URL·계정 확인**을 누른다.
2. Windows 설정 → 계정 → 회사 또는 학교 액세스로 이동한다.
3. **장치 관리에만 등록**을 선택한다.
4. 기관 안내와 실제 화면에 따라 이메일·관리 서버 URL·계정 정보를 입력한다.
5. Windows 연결 상태와 기관 MDM 관리자 화면에서 등록 결과를 확인한다.

실제 화면 순서는 Windows·기관 인증 구성에 따라 확인한다. 작업 후 **정보 숨기기**를 누른다. 탭 전환이나 표시 후 1분 경과 시에도 정보가 숨겨진다.

## 문제 확인

- 다운로드가 안 됨: 기존 바로가기의 서버 주소, PC 승인, 앱 공개 상태를 확인한다.
- 등록 정보가 안 보임: 배포 원본의 설정 파일 위치, JSON 형식, 파일 권한을 확인한다.
- 설치·등록이 실패함: 설치 오류와 기관 인증 오류를 구분해 확인한다. 다운로드 성공을 설치나 등록 성공으로 판단하지 않는다.

DuctTape는 수동 설치·등록 완료를 자동 확인하지 않는다. 변경 전에 이미 만들어진 설치 작업은 자동 취소되지 않는다.
