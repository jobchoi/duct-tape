# DuctTape v2 관리자 QR 생성·기능 설정

## 전제

QR 도구 변경이 반영된 v2 서버와 관리자 로그인이 필요하다. 기존 PC 시리얼을 쓰려면 해당 PC의 장치 정보 보고가 있어야 한다. 실제 라즈베리 배포·물리 스캔은 별도 확인 대상이다.

## QR 생성

1. PC 관리(`/admin`)에서 **도구·기능 관리**를 연다.
2. **QR 생성** 기능을 켠다.
3. 값을 직접 입력하거나 PC 목록의 **QR 만들기**로 시리얼을 가져온다.
4. 시리얼과 마지막 보고 시각을 실제 기기와 대조한다. 보고가 없으면 직접 입력한다.
5. **QR 생성 → PNG 다운로드**를 누른다.
6. 사용 전 QR을 읽어 입력값과 같은지 확인한다.

사용자 이름은 화면 메모이며 QR·PNG에 포함하지 않는다. 명단 업로드·라벨 PDF는 아직 제공하지 않는다. 최대 입력은 UTF-8 1024바이트이며 앞자리 0과 앞뒤 공백이 유지된다. URL을 입력해도 서버가 해당 주소를 방문하지 않는다.

## 기능 켜기·끄기

`/admin/tools`에서 QR과 MDM 다운로드·등록 정보 확인을 각각 설정한다. 변경은 서버 DB에 저장된다. 비활성 API는 새 요청을 거부한다. MDM을 끄면 클라이언트 목록의 Argos와 다운로드·등록 정보 조회를 막는다. 이미 받은 파일이나 실행 중인 작업은 취소하지 않는다.

## 오류 확인

- 관리자 연결 오류: `/admin`에서 로그인한 뒤 다시 연다.
- 시리얼 확인 전: 보고 유무와 PC 선택을 확인하고 직접 입력한다.
- QR 생성 거부: 기능 설정과 입력 길이·공백 여부를 확인한다.
- 이전 QR이 사라짐: 입력값을 바꾸면 이전 이미지를 무효화하므로 다시 생성한다.
- 서버 업데이트 후 모듈 오류: 의존성 갱신 또는 Docker 이미지 재빌드가 필요하다. v1과 v2 배포 경로를 구분한다.
