# QTP 헌장 검토 의견

2026-10-21 사용자가 제공한 종합 정리 문서를 검토했다. 원 운영 매뉴얼 v2.1이나 노트북 대화 원문을 확인한 것은 아니다. 다음은 제안이며 헌장을 임의로 확정/변경하지 않는다.

- 강점: 외적 지표보다 질문·이해 변화·기록의 지속성을 중심으로 둔 목적, 사실/의견 구분, 이해하지 못한 내용을 자신의 지식처럼 쓰지 않는 원칙.
- 명칭: Question Thinking Project와 Questioning Thinking Project가 섞여 있다. 공식 영문 명칭 하나를 확정할 필요가 있다.
- 권한: Claude의 최종 발행 판단과 작성자의 최종 결정이 충돌한다. 모든 AI는 검토 의견을 제시하고 작성자가 발행을 결정한다.
- 운영 비용: AI별 역할은 검토 관점으로 두고 매번 세 서비스를 순서대로 거치는 의무는 두지 않는 것을 권한다. 짧은 일지는 작성자 사실 확인으로 끝내고 주요 논증/교육 주장에 추가 리뷰를 적용한다.
- 글 범위: 하나의 핵심 질문은 주제를 좁히는 기준으로 쓰되 그 질문을 설명하는 보조 질문·연속 글을 허용한다.
- 검증 언어: 이해 검증을 정답 판정으로 좁히지 않고 자신의 말로 설명/작은 적용/예외 확인/남은 의문을 남긴다. 관찰과 자기 평가를 객관적인 학습 향상 증명으로 확대하지 않는다.
- 연구 범위: 개인 학습 시스템이라는 정의는 현재 목적에 부합한다. 교육 효과·학습 지속성 개선은 가설이며 참여자 동의·정보 보호·평가 기준 없는 성공 사례로 제시하지 않는다.
- 출판 자동화: 사실 기반 작업 기록에서 초안을 만들되 작성자의 승인 전 자동 공개하지 않는다. 실제 경험·감정·깨달음을 AI가 만들어 넣지 않는다.
