# 애플리케이션 모듈 구조

## 방향

Tools는 고정 설치 경로가 아니라 원본을 참고하는 후보 위치다. 초기 버전 `D:\work\tutor\backup\1007_usb\pc-setup\duct-tape`의 Main → 앱별 PowerShell 모듈 순서를 참고했다. 초기 버전은 읽기만 했으며 키·로그·백업 스크립트는 복사하지 않았다.

## 현재 분리한 역할

| 구성 | 역할 |
| --- | --- |
| Config/Applications.json | 앱 ID/표시 이름, 원본 후보, 필요한 파일, 키 파일 경로, 실행 모듈 순서. 실제 키 값 없음 |
| application_catalog.py / ApplicationMedia.ps1 | 원본 경로 해석과 메타데이터 검증 |
| DeploymentMedia | 앱 정의에서 준비 상태와 비공개 전송 ZIP 생성 |
| Main.bat | 관리자 권한·공통 사전 검사·공통 실행기 진입 |
| InvokeApplications.ps1 | 공통 모듈 뒤에 앱별 모듈을 정의된 순서로 실행. 오류 시 중단 |
| Modules/*.ps1 | 실제 앱별 탐지·제거·설치·상태 처리 |
| OfficeConfiguration.ps1 등 | 앱별 키/설치 설정 라이브러리 |

현재 순서는 정보 수집 → Office 확인/제거/설치 → 한컴 확인/설치로 유지했다. Main.bat에 앱별 실행 호출을 계속 늘리는 대신 등록한 모듈 목록을 사용한다. 실행 모듈은 검토한 Modules/의 PS1만 허용하고 경로 이동이나 임의 외부 명령을 받아 실행하지 않는다.

## 원본 위치와 클라이언트 위치

현재 앱은 기존 Office/, Hancom/ 및 Tools/Office, Tools/Hancom을 후보로 둔다. 완전한 원본을 우선 선택하며 안내 파일만 있는 빈 디렉터리를 준비된 원본으로 판단하지 않는다. 다른 위치를 사용할 때는 서버의 배포 원본 루트와 앱 후보를 명시한다.

실제 원본이 어디에 있든 ZIP은 앱의 media_folder 기준으로 정규화한다. 현재는 클라이언트 Office/, Hancom/이며, 키는 Config/에 따로 둔다. 클라이언트가 서버의 원본 절대 경로에 의존하지 않는다. 수동 BAT 실행에서는 같은 원본 해석을 사용한다.

한컴 참고 원본의 Install/InstallerConfig.ini에 LevelOption=1을 확인했다. 기존 setup.ini와 InstallerConfig.ini를 모두 검증하며 실제 원본을 임의로 다시 만들거나 설정을 덮어쓰지 않았다. 설치는 기존 MSI /qn 모듈을 사용한다.

## 새로운 앱을 추가할 때

1. 앱의 실제 설치/탐지/제거 방식과 라이선스 정책을 확인한다.
2. 검토한 Modules/ 모듈을 추가하고 Config/Applications.json에 원본·필수 파일·모듈 순서를 등록한다. 키가 없는 앱은 key_file을 null로 둔다.
3. 앱 전용 설정/키 처리가 필요하면 별도 라이브러리를 추가한다. 공통 원본 전송·경로 해석·실행기는 앱 이름별 분기를 추가하지 않는다.
4. 테스트에서 필수 파일 누락, 성공/실패/재부팅, 중복 실행과 키 노출을 검증한다.
5. 실제 새 앱을 붙일 때 보고 모델과 UI도 확장한다. 현재 Office/Hancom 보고 필드와 01~06 단계는 호환성을 위해 유지한다. 임의 새 단계의 보고를 이미 지원한다고 간주하지 않는다.

추가 앱 정의와 모의 07 모듈만으로 전송·공개 모듈 패키지·실행 순서를 확장하는 테스트를 추가했다. 실제 추가 제품의 설치 어댑터나 선택 설치 UI는 이번 범위에 포함하지 않는다.

## 실제 준비 상태와 한계

현재 Office는 기존 경로, 한컴은 Tools/Hancom에서 완전한 필수 진입 파일을 확인했다. Office의 세 파일은 ODT와 설치/제거 설정이며 오프라인 Office/Data 캐시는 확인되지 않았다. 실제 Office 설치는 구성에 맞는 인터넷 다운로드 또는 별도의 오프라인 원본이 필요하다.

준비 상태는 파일 접근과 실행 진입 설정을 확인한 것이며 실제 Windows 설치·정품 인증 성공을 뜻하지 않는다. 한컴 전체 원본은 약 1.08GB로 클라이언트 전송/압축 해제 공간이 필요하다. 실제 키·대용량 원본은 Git에서 제외한다.
