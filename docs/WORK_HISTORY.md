## 2026-10-07 기본 셋업 흐름 단순화

- 브랜치: `feature/simple-client-setup` → `develop` (`--no-ff` 병합).
- 관리자/클라이언트 화면의 상호 이동 메뉴와 수동 코드 교환을 제거했다. 최초 설치 도구가 자동 연결 요청을 보내고 관리자가 PC를 한 번 승인한다.
- 클라이언트는 바로가기로 자동 연결해 환경 셋업 버튼 하나만 사용한다. 보고 설정이 없으면 PC 전용 보고 설정을 자동 생성한다.
- 관리자 목록은 실제 에이전트가 연결된 PC만 선택 대상으로 표시한다. 보고만 있는 더미/미연결 기기는 대수만 안내하며 원본 데이터를 삭제하지 않는다. 선택 상태는 자동 갱신 후에도 유지한다.
- 기존 코드 등록 PC는 승인 상태를 보존한다. 새 요청은 승인 전 작업/보고를 차단하고 PC 전용 보고 인증은 자기 PC로 제한한다.
- MVC 구조와 기존 고정 작업·중복 방지·중단 복구 정책을 유지한다. 선택 옵션과 수동 작업 ID 입력을 기본 화면에서 제거한다.
- 검증: 관련 Python/UI 테스트 39개, PowerShell 작업 제한/구문 테스트 통과. 실제 서버에서 에이전트 0대·보고만 50대를 확인하고 화면/API HTTP 200 및 서버 갱신을 확인했다. 실제 Windows 설치 인수 검증은 별도다. 원격 push는 수행하지 않는다. 운영 절차는 [기본 환경 셋업](CLIENT_AGENT.md)에 반영한다.
