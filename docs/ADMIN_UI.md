# 관리자 화면 가독성 정리

2026-11-19. PC·제품 키·앱·도구 화면의 탐색과 정보 밀도를 조정했다.

- 상단: 현재 위치(브레드크럼) → 제목/짧은 설명/보조 작업 → 현재 메뉴 표시 탭.
- 기존 운영 서버에는 실제 지원하는 PC 관리·제품 키 메뉴만 노출한다. v2는 앱·도구 메뉴도 표시한다. 클라이언트 앱 화면에는 관리자 메뉴를 숨긴다.
- 공통 여백, 제목·본문·보조 글자 크기, 입력·선택 상자, 버튼 간격·포커스를 dashboard.css의 공통 관리자 블록으로 맞춘다.
- 제품 키: 새 키 입력/보관 이력 분리. 현재 적용·검증 전·정상·문제 상태는 색과 텍스트 배지로 함께 표시한다. 버전과 메모는 구분하고 마스킹 키는 고정폭 글꼴로 표시한다.
- 정상 이력의 중복 ‘적용/복구’ 버튼은 복구로 정리하고 표시 문구를 짧게 한다. 접근성 이름과 실제 확인 대화상자는 유지한다.
- 적용 안내·변경/작업 기록은 details로 접는다. 중요한 작업 조건은 각 확인 대화상자에서도 확인한다.
- 모바일은 입력 영역을1열로 바꾸며 넓은 표는 표 영역 안에서 가로 스크롤한다. 페이지 전체 가로 넘침을 막는다.

구현: Server/static/dashboard.css, Server/views/{admin,licenses,tools,applications}.html, licenses.js, applications.js/css. 기존 DOM ID/API 계약을 유지하며 서버 기능·키/이력 저장 방식·설치 스크립트는 변경하지 않는다.

## 검증

- Chromium PC 관리·앱 설치·제품 키 복구3개 통과(46.00초), QR 생성/다운로드1개 통과(6.69초).
- 제품 키 반응형 검사:1280/390px에서 본문 넘침 없음·입력 영역이 화면 안에 있음·탐색 노출·접힌 이력 확인(10.10초, 기존 기능 시험과 중복).
- 한글·긴 관리 이름/메모·마스킹된 가짜 키로 데스크톱/모바일 미리보기를 만들고 시각 확인했다. 위치: Git 제외 downloads/ui-preview/licenses-{1280,390}.png. 헤드리스 환경의 한글 글꼴 확인에는 해당 Windows PC의 기존 맑은 고딕을 임시 참조했다. 폰트 파일을 복사·배포하지 않았다.
- 실제 배포·복구 결과는 WORK_HISTORY의 최신 기록을 따른다.
