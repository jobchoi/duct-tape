# v1 보존 기준선

작성: 2026-10-16. 사용자 요청에 따라 시리얼 표시까지 포함한 현재 develop을 main에 병합해 코드 기준선으로 보존한다. v1.0.0-rc.1 태그를 사용하며 정식 안정 릴리스로 판정하지 않는다.

## 확인과 한계

- 사용자 현장 보고: Pi Docker/API/Funnel 접속, 한 탭북의 다운로드 후 설치 동작과 서버 셋업 완료 표시 확인.
- 알려진 미해결: Office/한컴 제품별 보고 불일치(정상/확인 전), 실패 후 재요청 무반응, 다중 PC 전송 지연, 재부팅 후 다운로드/설치 이어가기 미지원, 다중 PC 상세 진행 표시 개선 필요.
- MDM 설치는 현재 미구현이며 v2 범위다. 기존 Office/한컴 실행 경로를 MDM 설치 성공으로 해석하지 않는다.
- 시리얼 표시와 기존 관리자 선택/승인/요청 흐름은 JavaScript 실행 회귀 테스트로 확인한다. 이번 변경에서 실제 Windows 설치는 수행하지 않는다.

## 보존 범위와 운영

Git main/태그는 코드 보존이다. .env, 제품 키, 설치 원본, SQLite DB, 클라이언트 로그는 자동 백업되지 않는다. 실제 운영 백업은 작업 종료 후 서버를 멈추고 DB 일관성을 확보해 접근 제한된 별도 저장소에 보관해야 한다. 이 작업에서 Pi 데이터에 접근하거나 백업했다고 주장하지 않는다.

v1 코드는 main/태그에서 사용하고 v2는 develop의 feature 브랜치에서 진행한다. Pi는 검증된 버전을 고정해 사용한다. 서버 코드가 바뀌면 이미지 재빌드가 필요하지만 진행 중 다운로드/설치 때는 업데이트하지 않는다. 시리얼 표시만으로 DB 마이그레이션은 필요하지 않다.

복구/업데이트는 [Pi 배포](PI_DOCKER.md), 다음 개발 논의는 [v2 계획](V2_PLAN.md)을 따른다. 이 기준선을 남기는 것으로 알려진 오류가 해결된 것은 아니다.
