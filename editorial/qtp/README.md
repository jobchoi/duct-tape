# QTP 편집·학습 운영 문서

QTP는 DuctTape의 기능이 아니라 여러 프로젝트에 적용하는 질문·탐구·기록 활동이다. 이 디렉터리는 현재 저장소 안에서 별도 관리하는 편집 문서 영역이며 독립된 Git 저장소는 아니다. 여러 프로젝트에서 공동 사용하거나 버전/공개 주기가 달라지면 별도 저장소로 옮긴다. 아직 과도한 공유 패키지나 서브모듈은 만들지 않는다.

- [CHARTER.md](CHARTER.md): 목적·기록 원칙·책임. 도구나 요금제가 바뀌어도 유지할 기준.
- [OPERATIONS.md](OPERATIONS.md): 수동 협업·도구/API 기반 오케스트레이션 절차. 실행 방식이 바뀌면 갱신.
- [archive/2026-10-21-review.md](archive/2026-10-21-review.md): 개정 전 검토 의견. 현행 헌장으로 적용하지 않는다.

## 문서 경계

| 영역 | 기록할 내용 |
| --- | --- |
| docs/ | DuctTape 기획·구현·운영·테스트·작업 이력 |
| docs/blog/ | DuctTape 작업에서 파생한 게시 초안·플랫폼 연결·프로젝트별 게시 기준 |
| editorial/qtp/ | 프로젝트와 독립된 QTP 헌장·편집/학습 운영 |

DuctTape 작업 기록에는 QTP 문서 변경 사실과 경로만 남긴다. 헌장 전체나 일반 교육 논의를 프로젝트 기능 이력에 반복해서 넣지 않는다. 게시 초안은 원 작업 기록을 근거로 작성하고 헌장은 작성 기준으로 참조한다. 개발 완료와 편집 검토 완료는 별도 상태다.

## 개정 이력

2026-10-21: 사용자가 제공한 QTP 정리 및 수정 요청을 바탕으로 현행 개정본을 작성했다. 원 운영 매뉴얼 v2.1 전체를 확인하거나 그대로 복원한 문서는 아니다. 기존 표기의 Question Thinking/Questioning Thinking 중 영문 정식명은 아직 확정하지 않고 QTP 약칭을 사용한다. AI 역할을 서비스명 대신 기능으로 구분하고 작성자에게 발행 결정을 일원화했다. 유료 도구/API 오케스트레이션은 가능한 운영 방식으로 정리했으며 실제 연결·실행하지 않았다.
